# real-debrid.com

[real-debrid.com](https://real-debrid.com) is an unrestricted downloader
that allows you to stream and download files you find on the internet,
typically torrents and sharehoster content.

Paths are specified as `remote:path`.

Paths may be as deep as required, e.g. `remote:directory/subdirectory`.

## Configuration

Here is an example of how to make a remote called `remote`.  First run:

```console
rclone config
```

This will guide you through an interactive setup process:

```text
n) New remote
r) Rename remote
c) Copy remote
s) Set configuration password
q) Quit config
n/r/c/s/q> n
name> remote
Option Storage.
Type of storage to configure.
Choose a number from below, or type in your own value.
...
XX / real-debrid.com
   \ "realdebrid"
Storage> realdebrid
Option api_key.
please provide your RealDebrid API key.
Enter a string value. Press Enter for the default ("").
api_key> <your api key>
```

The `api_key` is obtained from the [RealDebrid account settings](https://real-debrid.com/apitoken)
after logging in.

### Directory layout

By default the remote mirrors the Torrents page: each torrent appears as
a folder and the torrent files are listed inside it. The `folder_mode`
option switches to showing every file directly in the root, and
`download_mode` selects between the `/torrents` and `/downloads` pages.

### Modification times

real-debrid.com does not store modification times of files, so
comparisons between real-debrid.com and other remotes are made by size.

### Advanced options

Here are the Advanced options specific to realdebrid (real-debrid.com).

#### --realdebrid-download-mode

please choose which RealDebrid directory to serve: For the /downloads page, type "downloads". For the /torrents page, type "torrents". Default: "torrents"

Properties:

- Config:      download_mode
- Env Var:     RCLONE_REALDEBRID_DOWNLOAD_MODE
- Type:        string
- Default:     "torrents"

#### --realdebrid-folder-mode

please choose wether files should be grouped in torrent folders, or all files should be displayed in the root directory. For all files in root type "files", for folder structure type "folders". Default: "folders"

Properties:

- Config:      folder_mode
- Env Var:     RCLONE_REALDEBRID_FOLDER_MODE
- Type:        string
- Default:     "folders"

#### --realdebrid-redownload-broken-torrents

whether to redownload torrents that are marked as dead. Default: false

Properties:

- Config:      redownload_broken_torrents
- Env Var:     RCLONE_REALDEBRID_REDOWNLOAD_BROKEN_TORRENTS
- Type:        bool
- Default:     false

#### --realdebrid-regex-shows

please define the regex definition that will determine if a torrent should be classified as a show. Default: "(?i)(S[0-9]{2}|SEASON|COMPLETE|[^457a-z\W\s]-[0-9]+)"

Properties:

- Config:      regex_shows
- Env Var:     RCLONE_REALDEBRID_REGEX_SHOWS
- Type:        string
- Default:     "(?i)(S[0-9]{2}|SEASON|COMPLETE|[^457a-z\\W\\s]-[0-9]+)"

#### --realdebrid-regex-movies

- Config:      regex_movies
