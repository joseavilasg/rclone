# TelDrive

[TelDrive](https://teldrive.it) is a self-hosted file storage system
that stores files on Telegram. It splits files into chunks and rebuilds
them on download, using a BLAKE3 tree hash to verify integrity.

Paths are specified as `remote:path`.

Paths may be as deep as required, e.g. `remote:directory/subdirectory`.

## Configuration

Here is an example of how to make a remote called `remote`.  First run:

```console
rclone config
```

This will guide you through an interactive setup process:

```text
n) New remote
r) Rename remote
c) Copy remote
s) Set configuration password
q) Quit config
n/r/c/s/q> n
name> remote
Option Storage.
Type of storage to configure.
Choose a number from below, or type in your own value.
...
XX / TelDrive
   \ "teldrive"
Storage> teldrive
Option access_token.
Access Token Cookie
Enter a string value. Press Enter for the default ("").
access_token> <your token>
Option api_host.
Api Host
Enter a string value. Press Enter for the default ("").
api_host> https://teldrive.example.com
```

The `access_token` is the session token obtained after logging in to
your TelDrive web interface. The `api_host` is the base URL of your
TelDrive server.

### Uploads

Large files are uploaded in chunks sized between 64 MiB and 2000 MiB
(the default is 512 MiB, which balances BLAKE3 tree-hashing efficiency).
The uploads support resuming when a transfer is interrupted, and the
`upload_concurrency` option controls how many chunk uploads run in
parallel.

### Modification times

TelDrive stores the modification time of uploaded files, so comparisons
between TelDrive and other remotes are made by modification time.
